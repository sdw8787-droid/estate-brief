# estate brief

국내·해외 부동산 투자·운용 담당자를 위한 모닝 브리핑. 토스의 간결한 화면 구성을 참고했습니다.

핵심 5개와 추가 텍스트 소식, 필터·검색·기기별 북마크를 지원합니다.

매일 한국시간 오전 7시 GitHub Actions에서 공개 RSS를 수집하고 Pages에 배포합니다. RSS 제목·설명 기반 자동 요약으로, 영어 기사는 영어로 표시될 수 있습니다. 기사 전문을 읽은 AI 요약과는 다릅니다. 뉴스가 부족하면 이전 참고자료를 명시하여 채웁니다. 예약 실행은 지연될 수 있습니다.

초기 화면은 2026-10-25 확인한 공개 리서치입니다. 기사 발행일과 정리일은 구분합니다. 원문 링크에서 세부 내용을 확인하세요.
